# B2 数据底座：动态字段、档案、合同与 Excel

本文说明 B2 的数据模型、写入路径与验收证据。对应 bead `te-h7l.12`。

## 设计原则

- **字段由用户定义**：开发期与演示用到的每个样例字段都通过 `service.CreateField`
  （产品「新建字段」的同一实现）创建，不存在代码写死的样例字段或固定 Excel 表头。
- **最小单元、配置驱动**：字段定义决定录入表单、Excel 模板/台账列、模板占位符。
- **本机存储**：定义与数据都在 `<data>/tengshou.db`，随 B9 备份整体迁移。
- **旧数据只增不改**：字段改名、改类型、归档都不会重写 `data_json`；旧值保留。

## 数据表

| 表 | 作用 |
| --- | --- |
| `field_definitions` | 字段定义：实体（contract/party）、键、名称、类型、必填、默认值、选项、台账/模板开关、内置标记、归档、排序 |
| `contracts` | 合同：`contract_no`（唯一、不可变）、`year`、`type`、`amount`、`asset_id`（租赁房产）、`lease_start`/`lease_end`（租期）；动态值在 `data_json` |
| `parties` | 相对方档案；动态值在 `data_json` |
| `change_log` | 追加式变更记录：实体、实体 id、动作、操作者、摘要、字段级 diff |

迁移 `0003_b2_fields.sql` 会：

1. 给 B1 旧库补 `contract_no`/`year`/`type`/`amount`，从 `signed_on`/`created_at`
   回填年度；旧合同编号补为 `LEGACY-<id>`；
2. 建立合同编号部分唯一索引与年度索引；
3. 建立字段定义表并种入内置字段（合同 10 个、档案 6 个）；
4. 建立变更记录表。

## 内置字段

合同：合同编号、年度、合同名称、合同类型、相对方、金额（元）、签订日期、
租赁起租日、租赁到期日、生效日期、到期日期、状态。相对方：名称、类型、证件号、
电话、地址、备注。（v0.2 迁移 `0011` 追加租赁起止日两个内置字段。）

**三方模型（v0.2）**：合同引用甲方档案、乙方（租户）档案与租赁房产档案
（`asset_id`）；租期 `lease_start`/`lease_end` 与合同自身的生效/到期日期分开。
房产的「在租/空置」由「存在生效中（active）且未终止的合同」派生，不手工维护；
合同到期不会自动释放房产（决策 D4），只产生只读提醒 `expiry_state`
（`expiring`：30 天内到期；`expired`：已到期未续签）。

**合同生命周期（v0.2，迁移 `0012`）**：状态机为
`draft` / `active` / `terminated` / `archived`。终止是显式动作，必须记录终止日期
（`terminated_on`）与原因（`termination_reason`：early 提前退租 / void 作废 /
other 其他 / renewal 续签联动），合同保留在台账并可按「已终止」筛选，房产随之
恢复空置。资产占用硬校验：保存生效合同与同一房产其他生效、未终止合同的租期重叠时
阻断保存，报错写明冲突合同编号；草稿只提示；未填完整租赁日期的历史合同不参与
硬校验（仅提示）。续签合同生效时，旧合同自动置为已终止（原因续签，终止日期默认旧
合同到期日）；若新合同起租日早于旧合同到期日，需要用户确认后按新起租日前一天终止。

内置字段可以修改显示名称、排序、默认值和台账/模板开关；键与类型不可改，核心字段
（编号、年度、名称、相对方）保持必填。用户字段支持类型：文本、长文本、数字、金额、
日期、单选、是/否、图片路径。

## 合同编号

- 留空自动生成 `HT-<年度>-<4 位序号>`；可用自定义编号（≤64 字符、无控制字符）。
- 数据库部分唯一索引 + 服务层检查双重保证唯一。
- 创建后不可修改；未来收款等模块按编号关联。
- 年度可从签订日期推导，也可显式填写；年度变更不改变编号。

## 写入路径与安全

- `/api/v1/*` 保持**只读**，需 Bearer 令牌，供外部 agent 使用。
- `/app/api/v1/*` 是应用写入面：
  - 仅接受本机回环请求（桌面 WebView 的进程内请求也视为本机）；
  - 写请求必须带 `X-Tengshou-App: 1`（迫使跨站页面走 CORS 预检）；
  - 带 `Origin` 时只允许同源、回环、`wails://` 等桌面来源；
  - JSON 请求体上限 32 MiB。
- 所有写入经过 `internal/service`：校验、编号、自动建档、变更记录统一在此完成。

## 校验与重复提示

- 必填、类型、格式（数字/金额/日期/单选/是-否）、金额非负、合同编号唯一。
- 日期接受 `YYYY-MM-DD`、`YYYY/M/D`、`YYYY年M月D日` 与 Excel 日期序号。
- 金额接受千分位、`¥`/`￥`/`元` 等常见写法。
- 同一相对方 + 年度 + 合同名称已存在时给出非阻断提醒。
- 相对方同名提醒；合同引用中的同名档案要求从档案中明确选择。
- 被合同引用的相对方禁止删除。

## Excel 录入与合并

- **模板**：列 = 当前启用的合同字段（B14 起不再按「出现在台账」过滤），顺序由字段
  排序决定；`填写说明` 工作表列出列名、键、类型、必填、默认值、说明；单选/是-否
  带下拉校验。
- **导入预览**：解析首个非说明、非技术工作表，按表头自动映射（先按显示名，再按键），
  也可手工指定列映射；逐行给出 `新增 / 更新 / 不变 / 错误`、错误字段与警告。
- **合并规则**：存在同编号合同则更新；空白单元格表示「保持不变」，非空才覆盖；
  无编号的行在写入时分配新编号。新增录入与更新编辑共用同一套预览→合并机制。
- **错误行**：预览列出 Excel 行号与字段原因；默认存在错误行时整批不写入，
  也可勾选「跳过错误行」只导入有效行。
- **导出**：台账列随字段定义动态生成，数值保持数值单元格；导出文件可直接改后导回。
  导出文件带隐藏的 `_合同ID` 列与 `_腾手快照` 工作表，用于识别更新、删除与冲突；
  没有快照的外部/旧版文件按普通合并处理。回合制细节见
  [b14-excel-roundtrip.md](b14-excel-roundtrip.md)。

## 年度视图与变更记录

- 合同列表支持 `year=YYYY` 与不传年度（跨年查询）；`/app/api/v1/contracts/years`
  返回各年度数量。年度只是字段/索引，不是分库断档。
- 变更记录包含创建、修改、删除、字段归档；修改记录字段级 `旧值 → 新值`，
  操作者默认为系统用户，可用 `config.json` 的 `operator` 覆盖。

## 验收证据

自动化测试：

```
go test -count=1 ./internal/service/     # 字段生命周期、编号不可变、校验、变更记录、跨年、Excel 往返/合并/映射
go test -count=1 ./internal/store/       # B1 旧库升级、回填、唯一索引、字段种子
go test -count=1 ./internal/httpapi/     # 应用写入面、回环/Origin/请求头防护、字段/合同/档案/Excel 端点
go test -count=1 ./internal/demo/        # 样例字段全部经 service 创建；跨年样例；PDF 闭环
```

手工冒烟（2026-11-22）：

```
tengshou-cli demo --data-dir /tmp/ts-b2-smoke
# 14 个字段经产品功能创建；2026 + 2025 两份合同；2 页 PDF
tengshou-cli serve --data-dir /tmp/ts-b2-smoke --port 18765 --loopback
GET /app/api/v1/bootstrap          → schema 3，操作者、年度计数、30 个字段
GET /app/api/v1/contracts?year=2025→ 1 份 2025 年合同（跨年查询）
GET /app/api/v1/excel/ledger       → 2 行台账；再预览 → unchanged 2
POST /app/api/v1/fields {floor_no} → 运行时新增「楼层」
GET /app/api/v1/excel/template     → 表头包含「楼层」（无需重启）
POST /app/api/v1/contracts {data.floor_no} → HT-2026-0001
POST /app/api/v1/fields 无 X-Tengshou-App → 403
```

## 明确不在 B2

- 字段间计算/联动、模板编辑器、签名采集、公章图片管理、MCP 连接器、手机扫码填表
  （D7 边界）分别留给后续 bead；字段模型已为这些能力保留扩展位（类型、选项、
  台账/模板开关、内置标记）。
- V2 字段矩阵回来后，可在现有字段模型上补齐字段与录入表单配置，无需改表结构。
