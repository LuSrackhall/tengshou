第一次使用

从您手上的模板开始

腾手不预置任何地方模板：导入上级或对方给过的 Word 模板（.docx）或现成 PDF，标好位置，就能生成合同。整个引导在本机完成，不需要联网。

样例数据，不写入台账

引导里的样例预览与试生成只使用示例数据：不会写入合同、档案、模板版本或生成记录。看懂了再录真实合同。

本机自检

运行自检会检查数据目录、数据库、Word 转换、局域网签名、字段 / 模板 / 样例就绪度、备份与磁盘空间，每项失败都给下一步。

模板体检

导入模板后，这里会比对模板占位与字段定义，指出未知字段、缺必填字段、缺签名或公章位置。

引导只做提示与校验，不改变您原有的模板、台账和生成流程；随时可从顶部导航重新打开。

记录谁在何时改了什么。操作者取自本机系统用户，可在 config.json 的 operator 中指定；通过 MCP 连接器的写入标记为「Agent（MCP）」。外部写入会在数秒内自动反映到本页与各列表。

所有数据都在本机数据目录：数据库、签名与公章图片、模板文件、已生成的 PDF 和配置。备份包包含上述全部内容（不含日志），换电脑时可在新机器上恢复。备份包未加密，请像保管合同原件一样保管它。

MCP 连接器让本机 AI agent（Claude Code / Claude Desktop）读写腾手数据。连接器以 stdio 运行、只走本机回环，本面板不会启动或停止它。
